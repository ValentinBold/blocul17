# Contribuții

Pentru buguri, deschide un Issue cu versiunea, pașii de reproducere și rezultatul așteptat. Pentru o idee, folosește formularul de sugestii. Nu publica date personale sau fișiere de autentificare.

Pentru o modificare de cod:

1. Creează o ramură, de exemplu `feature/inventar` sau `fix/salvare`.
2. Modifică sursele și adaugă verificări relevante când schimbi comportamentul.
3. Rulează `./test.ps1` pe Windows. Actualizează documentația dacă se schimbă comenzile sau mecanicile.
4. Deschide un Pull Request către `main`, cu problema rezolvată și verificările efectuate.
5. După verificările automate și revizie, modificarea poate fi integrată.

Nu încărca `build/`, `qa/`, arhive locale sau salvări personale. Executabilele se distribuie prin Releases. Nu prelua grafica sau hărțile jocurilor comerciale.

Codul folosește C# compatibil cu compilatorul .NET Framework inclus în script. Păstrează posibilitatea de compilare fără dependențe externe.

Trimiterea unei contribuții implică publicarea ei sub licența MIT a proiectului.
